# Forbidden Magic: Reforged

Порт Forbidden Magic 0.574 (Minecraft 1.7.10, SpitefulFox) на Thaumcraft 4: Reforged. Основной таргет — Minecraft 26.3; 1.21.1 — отдельный второй таргет после завершения и зелёного гейта 26.3.
Логика, числа, рецепты, тексты и ассеты оригинала переносятся 1:1, где это допускает современный API.

## Источники истины

- Игровое поведение и данные оригинала: `../ForbiddenMagic`.
- API хоста: `../thaumcraft-4-reforged`; используемый исходный коммит закреплён в `host.sha`.
- `docs/fidelity.md` — единственный ledger отличий и подтверждённых приближений.
- `docs/roadmap.md` — только текущие незакрытые задачи и критерии завершения.
- `docs/verification.md` — последний подтверждённый CI и проверки, которые ещё не автоматизированы.
- `../thaumic-tinkerer-reforged` — сторонний хост под ARR; интегрироваться только через публичный API, не копировать его код или ассеты.

## Правило паритета

- Любое утверждение о поведении оригинала сначала проверяй по `../ForbiddenMagic`, а затем по фактическим точкам вызова, рецептам и research в порте.
- Современный API вместо старой идиомы сам по себе не является расхождением. Реальные отклонения и ограничения записывай в `docs/fidelity.md`.
- Не объявляй полный паритет по одному лишь успешному компилятору или GameTest. Для визуальных и боевых сценариев нужен реальный клиент/игровая проверка.
- Баги оригинала исправляй только когда они ломают игру; иные отклонения документируй.

## Хост и сборка

- Хост закреплён в `host.sha`; `tools/prepare_host.py` заново создаёт локальную копию `host/` из пина и `patches/*.patch`. `host/` и локальный Maven не коммитятся.
- Изменения хоста — только в `patches/*.patch`. Не редактируй `host/` вручную: подготовка его уничтожит. Перегенерируй патчи из коммитов `host/` через `tools/prepare_host.py --export`.
- Хост имеет лицензию All Rights Reserved. Не включай его классы/ассеты в jar аддона и не распространяй собранный host jar.
- Полный CI-гейт: подготовить закреплённый хост, собрать хост и аддон через composite build, проверить происхождение jar и запустить `runGameTestServer` с `no_lust=false` и `no_lust=true`.
- Перед релизом дополнительно запускай `tools/gen_resources.py` дважды и проверяй чистый diff; для моделей, creative-вкладки и рендера нужен `runClient`.
- Хост подключается композитной сборкой: `settings.gradle` подменяет `thaumcraft:thaumcraft` проектом `:host`, поэтому публикация в локальный Maven не нужна, а `host/` обязан существовать до конфигурации сборки. Версия хоста в `host/gradle.properties` должна совпадать с `thaumcraft_version`, иначе сборка падает с явным сообщением.

## Данные и стиль

- Источники ресурсов — `data/` и генераторы `tools/`; результат находится в `src/generated/`. Не исправляй сгенерированные файлы вручную.
- Поддерживаемые языки — `en_us` и `ru_ru`; формулировки оригинала сохраняй.
- Тесты — GameTest.
- Java и Python: 4 пробела, без комментариев. Сообщения коммитов — на английском, Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`), без строк соавторства.

## Git

- `main` — каноническая ветка. Для личной работы коммить изменения прямо в `main`, если пользователь не попросил иное; не создавай PR ради собственных изменений.
- Не переписывай историю `main` и не используй force-push. Перед коммитом сверяй актуальный HEAD, потому что удалённая ветка может обновиться параллельно.
- Добавляй только явно выбранные пути; не коммить `host/`, `reference/`, `run/`, журналы сессий и локальные конфиги.
- Не добавляй разовые планы, design-документы и дневники сессий в репозиторий. Долговечные результаты держи в `docs/fidelity.md`, `docs/roadmap.md` и `docs/verification.md`.

## Порт и зависимости

- modId `forbiddenmagic`, пакет `dev.visfox.forbiddenreforged`, версия из `gradle.properties`.
- Хостовая зависимость обязательна: `thaumcraft`, версия `1.1.2` или новее — с этой версии API аспектов аддонов в апстриме. Локальные патчи нужны только для block aspect targets (точный аспект портала).
- Внешние интеграции не реализованы автоматически заменами на похожие моды. Их статус фиксируется в `docs/roadmap.md`.
