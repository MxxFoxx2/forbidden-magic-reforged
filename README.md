# Forbidden Magic (Reforged Port)

## 1. Название

Forbidden Magic: Reforged — неофициальный порт Forbidden Magic 0.574 (Minecraft 1.7.10, SpitefulFox)
на Thaumcraft 4: Reforged. Проект не связан с оригинальным автором; оригинал распространяется под
WTFPL, порт — под MIT (см. `LICENSE` и `NOTICE`).

## 2. Описание

Порт переносит контент, числа, рецепты и тексты оригинала на современный NeoForge-хост.
Текущий статус — срезы M1–M7b:

- M1 (тег `m1-rc1`) — аспекты, осколки, дропы, исследования и топор Череподрать;
- M2 (тег `m2-rc1`) — пять зачарований;
- M3 (тег `m3-rc1`) — хамелеоновы инструменты и оставшиеся три зачарования;
- M4 (тег `m4-rc1`) — скверные материалы;
- M5 (тег `m5-rc1`) — скверные растения;
- M6 (тег `m6-rc1`) — Арканный торт;
- M7a (тег `m7a-rc1`) — кристалл моба и таблица спавна;
- M7b (тег `m7b-rc1`) — Клетка Гнева: блок, спавнер, рендерер, исследование, рецепты.

Замеры гейтов — `docs/verification.md`, отступления от оригинала — `docs/deviations.md`.

### Что поддерживается

- Thaumcraft 4: Reforged `1.2` и новее на Minecraft `26.3`.
- Семь аспектов: `luxuria`, `infernus`, `superbia`, `gula`, `invidia`, `desidia`, `ira`.
- Таблица меток `DarkAspects`, семь осколков грехов и Осколок Чревоугодия.
- Дропы осколков, категория `FORBIDDEN`, записи `NETHERSHARDS` / `HELLFIRE` / `SKULLAXE`.
- Восемь зачарований: Wrath, Capitalist, Consuming, Educational, Corrupting, Cluster, Impact,
  Voidtouched, с исследованиями и infusion-рецептами.
- Четыре хамелеоновых инструмента с тремя переключаемыми наборами зачарований (Shift + ПКМ).
- Скверные материалы и растения: бревно, доски, камень, кирпичи, блок звезды, листва, саженец,
  Чернильный цветок и Куст Теней.
- Кристалл моба: таблица из 42 мобов (24 vanilla + 18 Thaumcraft) «моб → аспект», пустой и
  заполненный варианты через компонент `forbiddenmagic:mob_id`, импринт при убийстве игроком,
  конфиг `wrath_cage` / `wrath_cost` / `wrath_eff` / `wrath_crazy`.
- Клетка Гнева: блок с block entity, спавнер мобов на эссенции, вставка кристалла моба,
  клиентский рендерер моба внутри клетки, исследование `WRATHCAGE`, инфузионный рецепт и
  тигельный рецепт кристалла.
- `no_lust` как STARTUP-конфиг; значения на клиенте и сервере должны совпадать.
- Опциональная интеграция с Thaumic Tinkerer Reforged: стоимость восьми зачарований в энчантере.

### Чего нет в этой вехе

- Вилка дьяболаста, жезлы и фокусы, скруное дерево, житель-еретик — см. `docs/roadmap.md`.
- Blood Magic, Botania, Ars Magica 2, CoFH не поддерживаются: под NeoForge 26.3 этих портов нет.
- Minecraft 1.21.1 — второй таргет, ещё не начат.
- `plans.txt` оригинального автора не реализуется: это незавершённый список идей.

### API

Хостовый API аспектов расширен патчами `patches/`: реестр аспектов, регистратор аддона и слияние
entity-тегов. Аддон использует публичные точки хоста — `AddonAspects`, `AspectRegistry`,
`InfusionRecipe`, `ResearchItem`, `EnchantmentManager` TT (через reflection). Описание патчей и
порядок применения — `docs/upstream.md`.

## 3. Установка

Нужен Thaumcraft 4: Reforged `1.2` с аддон-аспект-API. Если официального релиза хоста с этим API
ещё нет, используй патчер: примени `patches/` к своему клону хоста, собери его и положи рядом
собранный jar порта. Сам jar хоста проект не распространяет.

Сборка из исходников:

```bash
python tools/prepare_host.py
cd host && cmd //c gradlew.bat publish && cd ..
cmd //c gradlew.bat build
```

`tools/prepare_host.py` клонирует хост из соседнего каталога `../thaumcraft-4-reforged` — склонируй
его туда заранее или поправь путь. Пин хоста лежит в `host.sha`. На Linux/macOS замени
`cmd //c gradlew.bat` на `./gradlew`. Артефакт —
`build/libs/forbidden-magic-0.574-26.3-port.0.1.0.jar`.

Тесты:

```bash
cmd //c gradlew.bat runGameTestServer
```

## 4. Использование

- Исследования начинаются со «Сетевых осколков» (`NETHERSHARDS`) в категории `FORBIDDEN`;
  дальше открываются `HELLFIRE`, `SKULLAXE`, `MORPHTOOLS`, зачарования и растения.
- Осколки грехов падают по правилам оригинала: гнев — за убийства, гордость — с боссов,
  лень — за смерть без игрока, жадность — за добычу с Looting, зависть — с зомби-свинозверя
  с осколком в руке.
- Хамелеоновы инструменты: Shift + ПКМ переключает один из трёх наборов зачарований и стоит
  5 прочности. Ремонт — осколком зависти.
- `no_lust = true` в `config/forbiddenmagic-startup.toml` убирает `luxuria`, осколок lust и
  связанные рецепты; значение должно совпадать на клиенте и сервере.
- `enchanting = false` отключает эффекты, исследования и рецепты зачарований.
- При установленном Thaumic Tinkerer Reforged стоимость зачарований появляется в его энчантере.

## 5. Структура репозитория

```
src/                 исходный код аддона и ресурсы
  main/java/         Java-код (Gradle-конвенция)
  main/resources/    ассеты, data-паки, теги, рецепты
  generated/         сгенерированные модели, blockstates и lang
tests/               GameTest-тесты (подключаются в sourceSets)
docs/                спека, планы, отступления, roadmap, verification, upstream
data/                исходные данные: data/lang/*.toml, data/id_map.json
tools/               генератор ресурсов, подготовка хоста, проверки, vineflower
patches/             патчи к хосту (0001–0003)
build/               артефакты сборки, в git не хранится
host/                локальная патченная копия хоста, в git не хранится
maven/               локальный maven с хостом 1.2, в git не хранится
run/                 рабочая директория игры, в git не хранится
```
