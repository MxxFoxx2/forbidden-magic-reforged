# Minecraft 1.21.1 target

This branch targets the `mc/1.21.1` line of `notlikethiss/thaumcraft-4-reforged`. It is intentionally separate from the main 26.3 port.

## Build target

- Java 21
- Minecraft 1.21.1
- NeoForge 21.1.256 (aligned with the pinned host)
- ModDevGradle 2.0.148
- Gradle wrapper 9.2.1
- Parchment 1.21.1 / 2024.11.17
- TerraBlender 1.21.1-4.1.0.1
- JEI 19.57.0.451
- Thaumcraft dependency version 1.1

## Host patches

The files in `patches/` are specific to the pinned 1.21.1 host commit in `host.sha`:

1. `0001-aspect-registry.patch` converts Thaumcraft's closed `Aspect` enum into a deterministic ordered registry while preserving the 48 built-in aspect identifiers and their order. It also removes enum-only assumptions from aspect orbs and wand vis.
2. `0002-aspect-addon-init.patch` adds a minimal addon aspect registration API and invokes it before Thaumcraft builds its aspect tags.
3. `0003-host-publish.patch` publishes the patched host artifact into the local Maven repository consumed by this addon.

The patches are applied only to `host/`, a disposable copy. The sibling upstream checkout is treated as read-only.

## Prepare and build

From a checkout where `thaumcraft-4-reforged/` is beside this repository:

```powershell
python tools/prepare_host.py --rebuild
./gradlew build
./gradlew runGameTestServer
```

On Windows, use `gradlew.bat` for the final two commands. The preparation script pins the upstream commit, validates that each patch applies cleanly, applies the patches, and can build/publish the host artifact.

GitHub Actions runs the same preparation and build flow on pushes and pull requests targeting `1.21.1`. A green CI run is the build validation gate; it does not replace visual client testing.

## Resource intake

The initial resource-only transfer brought in 85 texture/animation assets, English and Russian language data, generated localization JSON and `data/id_map.json`. Models, blockstates, registrations, recipes and gameplay source still need to be ported as separate feature slices; asset transfer alone does not constitute a complete port.
