# Minecraft 1.21.1 adaptation status

## Verified build target

- Minecraft 1.21.1, Java 21, NeoForge 21.1.256.
- Host source is pinned to Thaumcraft 4: Reforged branch `mc/1.21.1`, commit `17dd73087e52bf918cd7f580abd2114e44f88544`.
- The workflow builds a disposable patched host, publishes it to the sibling Maven repository, builds the addon and runs NeoForge GameTests.
- Latest successful host + addon build before the next test expansion: [GitHub Actions run](https://github.com/MxxFoxx2/forbidden-magic-reforged/actions/runs/40129968353).

## Ported and currently compiled

- Ordered add-on aspect registry on the host, preserving 48 built-in aspect identifiers and ordinal order.
- Seven Forbidden Magic sin aspects: Luxuria, Infernus, Superbia, Gula, Invidia, Desidia and Ira, respecting the no-Lust config option.
- Base items: sin shards, taint coal/fruit, black dye, emerald fragment and the tainted/infernal/profane/witchwood wand rods.
- Item and block aspect tags; taint coal fuel value (random 1–2400 ticks); taint fruit warp/hunger effect; sheep dye behavior.
- Tainted log/planks/leaves/sapling/stone, star block, Umbral Rose / rose bush, and regenerating Thaumic Cake block.
- Item models, blockstates/models, block loot tables, base vanilla recipes, aspect textures and English/Russian language keys.
- Thaumcraft recipes for taint sapling, Umbral Rose, taint stone, Thaumic Cake, tainted rod and infernal rod.
- A Forbidden Magic research category with entries for Nether shards, taint tree/stone, Umbral Rose, Thaumic Cake, tainted rod and infernal rod.
- Tainted and infernal rod registrations in Thaumcraft's 1.21.1 wand registry; tainted-land and Nether refilling/defensive effects.

## Deliberately not marked as ported yet

Several remaining `dev` sources target Minecraft 26.3 APIs and remain isolated under `porting/26.3-staging/src/main/java/`. They must be rewritten against 1.21.1 instead of included via global import replacements.

Remaining feature slices include the Wrath Cage and imprinting crystal (block entity persistence, mob spawning and interaction), most custom tools and enchantments, focus upgrades, villagers/entity additions, full research tree and visual models/renderers, world-generation integration, and manual in-client visual checks. Some of these need APIs/data formats specific to 1.21.1.

## Fast host-neutral unit-test gate

The pure core catalogs are also covered by a JUnit 5 gate that runs in milliseconds via `gradlew test`, without booting a Minecraft server. It complements — does not replace — the runtime GameTests.

- `src/test/java` holds 23 tests in four classes: `RecipeCatalogTest` (7), `ResearchCatalogTest` (6), `AspectCatalogTest` (6) and `ContentIdTest` (4).
- `RecipeCatalogTest` is adapted to this track's six-argument recipe `Options` (no `arsMagicaLoaded` flag, since Ars Magica integration is not ported to 1.21.1); the aspect, research and `ContentId` tests are shared verbatim with the other tracks.
- `build.gradle` adds the JUnit BOM 5.11.4 platform, `junit-jupiter`, the platform launcher and `useJUnitPlatform()`; `build` → `check` → `test` runs the gate.
- `.github/workflows/build-1.21.1.yml` runs `./gradlew --no-daemon test` after the host build and before the addon build.

Local verification (12 November 2026, offline against the pinned host):

- Unit tests: 23/23 passed (`gradlew test`, BUILD SUCCESSFUL).
- GameTests: 135/135 passed with Luxuria enabled and 135/135 with `no_lust=true`.
- Host-agnostic boundary check passed (55 neutral Java files; 100 production Java files checked outside the TC4 adapter).

These are local/headless results; they confirm compilation and the covered logic, not manual in-client visual behavior.

## Validation

On every push and pull request to branch `1.21.1`, GitHub Actions:
1. checks out the pinned Thaumcraft source and applies the target-specific patches;
2. builds/publishes Thaumcraft;
3. runs the fast host-neutral JUnit gate (`gradlew test`);
4. builds the addon;
5. runs GameTests for host loading, built-in aspect order, add-on aspect serialization, recipe/research registration, rod registry, block/item registration and the taint coal fuel range, in both `no_lust` modes.

A green workflow confirms code compilation and the covered tests; it does not imply that all Forbidden Magic content has already been ported or replace manual visual testing.
