# Отступления от оригинала

| Что | Оригинал 1.7.10 | Порт | Причина |
|---|---|---|---|
| Портал | `new ItemStack(Blocks.portal)` + `infernus` 4 | `minecraft:obsidian` + `infernus` 4 | у блока портала нет предметной формы; тег ставится на рамку |
| `itemBacon` | OreDictionary `itemBacon` + `gula` 6 | не регистрируется | в хосте нет аналога; отмечено в `docs/roadmap.md` |
| Теги FM-блоков и ресурсов | taint wood, star block, taint stone и т.д. | отложены до полного §5.1 | блоки и предметы ещё не портированы |
| Теги осколков | meta 0-6 одного предмета | добавляются в Task 7 после регистрации id | порядок регистрации |
| Метки сущностей | мутация `ThaumcraftApi.scanEntities` | `entityCopy` (merge) из патча 0002 | в API хоста не было слияния с базовыми метками |
| `ItemMobCrystal` | предмет FM | портируется | ядровой предмет без сторонних импортов, нужен Клетке Гнева |
| Осколок lust при `no_lust` | мета 4 переименовывается в `despair`, тег VOID 1 | предмет `lust_shard` остаётся зарегистрированным, но без тега, вне creative/дропа/рецептов | современный порт выражает отсутствие контента доступностью, а не переименованием |
| Топор Череподрать | полноценный инструмент | зарегистрирован как обычный предмет | поведение инструмента входит в полный §5.1; рецепт замыкается уже в M1 |
| `gluttony` 0/1/2 | рецепты Arcane Cake/Ring Food | поле конфига есть, рецепты — Task 10 | порядок инкрементов |
| Бонус wrath | урон инструмента/меча + sharpness/power/fire aspect/flame/smite/bane | `ATTACK_DAMAGE - 1` + те же зачарования + focus potency | современный attribute API не даёт исходный modifier один-в-один; числа проверяются в GameTest границей |
| Боссы для pride | `IBossDisplayData` | `WitherBoss`, `EnderDragon`, `ThaumcraftBoss` | явные типы вместо удалённого интерфейса |
| Taint-осколок из tainted-блоков | `FMEventHandler` на блоке | отложен до полного §5.1 | M1 проверяет цепочку на wrath; источник taint добавится вместе с taint-деревом |
| Иконка HELLFIRE | `new ItemStack(Blocks.fire)` | `minecraft:flint_and_steel` | у блока огня нет предметной формы |
| Картинки в страницах исследований | `<IMG>forbidden:textures/misc/research.png...` | `<IMG>forbiddenmagic:textures/misc/research.png...` | namespace порта; файл скопирован в `assets/forbiddenmagic/textures/misc/` |
| Corrupting: цель | `blockCustomOre` (infused stone) заменяет осколки стихий | тег `forbiddenmagic:infused_stones`, дроп `thaumcraft:*_shard` заменяется грешным осколком с шансом 1/3 | в 26.3 infused stone сам дропает осколки; выбор пула повторяет `getSinShard` (taint заменён на gluttony, lust выпадает при `no_lust`) |
| Стоимость зачарований | min/max enchantability 1.7.10 | `min_cost`/`max_cost` в JSON зачарования | зачарования недоступны на столе ни в оригинале, ни в порту, поэтому числа влияют только на infusion-рецепт |
| `enchanting = false` | зачарования не регистрируются | JSON остаётся в реестре, отключены эффекты, исследования, рецепты и TT-стоимость | датапак-записи нельзя снять конфигом; контент недостижим без рецепта |
| TT-интеграция | прямое обращение к `EnchantmentManager` | reflection по публичному API | TT под ARR и не входит в compile classpath; сборка порта от него не зависит |
| Cluster, Impact, Voidtouched | в этом слайсе | вместе с морф-инструментами | их эффекты в оригинале живут в классах инструментов, а исследования требуют `MORPHTOOLS` |
| Цвет фазы морф-инструмента | оверлей `eye*` красится в цвет фазы (красный/синий/жёлтый) | оверлей статичный | в слайсе нет item tint source; фаза видна по имени и набору зачарований |
| Переключение фаз | требует наличия NBT (первое зачарование) | работает всегда | компоненты существуют у любого стека |
| Impact: выбор плоскости | сторона удара из рейкаста | доминирующая ось взгляда | у `mineBlock` нет стороны; приближение проверяется тестом |
| Ремонт инструментов | энви-осколок через `getIsRepairable` | компонент `REPAIRABLE` с осколком зависти | современный механизм наковальни |
| Рецепты инструментов | `itemResource` мета 3 и `blockMagicalLog` мета 1 | `thaumcraft:enchanted_fabric`, `thaumcraft:silverwood_log` | соответствие мет TC4 предметам хоста |
| Рецепт Voidtouched | `itemResource` мета 16 | `thaumcraft:void_seed` | единственный предмет хоста, соответствующий мете |
| Скверный камень | один блок с метой 0/1 | два блока `taint_stone_smooth` и `taint_stone_brick` | в 26.3 нет метапредметов |
| Боковые текстуры скверного бревна | 75% чистых, 25% «gross» по позиции | всегда чистый `taint_log_side` | позиционный выбор текстуры не выражается blockstate |
| Арканный рецепт скверного камня | `addArcaneCraftingRecipe` с research `TAINTSTONE` | отложен до слайса исследований скверны | нужен research-ключ и предмет `resourceTaint` |
| Плавка скверного бревна | `taint_charcoal` | отложена | предмет ещё не портирован |
| Скверный плод | листва редко роняет `taintFruit` | не реализовано | предмет плода ещё не портирован |
| Распространение скверны | скверные блоки участвуют в заражении мира | не подключено | хост держит список блоков жёстко, как записано в спеке; наши блоки вне его |
| Бонемил Куста Теней | `spreadFlowers` на костной муке | куст не распространяется костной мукой | в этом слайсе нет IGrowable; распространение цветка есть |
| Чернила | цветок → 2 чёрных красителя | отложено | нужен предмет `resource` |
| Арканный торт: восстановление | срез возвращается на random tick | то же | поведение оригинала сохранено |
| Арканный торт: дроп | блок не дропается | `noLootTable()` | торт нельзя перенести после установки, как в оригинале |
| Арканный торт при `gluttony = 1` | рецепта нет | рецепт не регистрируется, исследование остаётся со страницей без рецепта | как в оригинале |
| Последний кусок торта | ширина среза 12/12 даёт вырожденный бокс | ширина ограничена 14/16 | оригинальный бокс на последнем куске пустой |
| Импринт кристалла | в оригинале требуется убийство вилкой дьяволиста | импринт срабатывает на любое убийство игроком, пока вилка не портирована | гейт вилки добавится вместе с предметом |
| Кристалл моба: варианты | мета 0/1 в одном предмете | компонент `forbiddenmagic:mob_id`, модель через `has_component` | в 26.3 нет метапредметов |
| Импринт | любой моб из Config.spawnerMobs + wrathCrazy | карта современных id в FmSpawnerMobs | имена 1.7.10 заменены на id 26.3 |
| Клетка Гнева: центр инфузии | `arcane_stone` (по плану) | `thaumium_block` | сверено с референсным датапаком 1.21.1: центр — блок таумия |
| Клетка Гнева: банки | `empty_warded_jar` (специальный тип ингредиента) | `thaumcraft:warded_jar` (обычный предмет) | в хосте нет отдельного предмета пустой банки; `warded_jar` — блок-банка без эссенции |
| Клетка Гнева: рендерер | `getOrCreateRenderEntity` + старый `render()` | `extractEntity/submit` с временной сущностью | современный API рендеринга с разделением на извлечение состояния и отправку |
| Клетка Гнева: вилка | вилка дьяболаста переключает режимы эссенции | отложено | вилка не портирована; режимы переключаются автоматически по приоритету (mob aspect → ira → desidia) |
