# Forbidden Magic: Reforged 2.0.0 — Host-Agnostic Core

This is a major architecture release for the Minecraft 26.3 / NeoForge 26.3 track. It moves the mod's shared content definitions and extracted gameplay rules behind a host-neutral core and an explicit Thaumcraft 4: Reforged adapter.

## What is new

- **Shared content model:** semantic `ContentId` values and host-neutral catalogs for aspects, recipes, and research.
- **Explicit host adapter contract:** `HostAdapter`, `HostProfile`, and a capability registry separate registration/lifecycle integration from common content.
- **Focused runtime capabilities:** entity aspects and classification, wand inspection/Vis/parts, warp, taint, enchantments, item factories, accessories, scribing, and block-entity integration are exposed through narrow contracts rather than monolithic host services.
- **TC4 integration boundary:** TC4 registry values, wand APIs, Essentia interfaces, research/recipe APIs, and host-specific item implementations are kept in `integration/tc4`.
- **Honest feature support:** host features are declared as `NATIVE`, `ADAPTED`, `PARTIAL`, or `UNSUPPORTED`; missing host mechanics are not silently approximated.
- **Preserved gameplay checks:** the refactor adds boundary checks and GameTests around semantic warp pools, wand ports, Profane Wand transitions, entity aspect catalogs, and Wrath Cage bridges.

## Compatibility and scope

- Runtime target: **Minecraft 26.3 / NeoForge 26.3 / Thaumcraft 4: Reforged 1.1.2**.
- This release does **not** include a second magic-host adapter. The Thaumaturge work is an API compatibility audit, not a tested integration.
- This release does **not** combine multiple Minecraft versions into one binary. Version-specific build and release tracks remain separate.
- Full visual/client parity is not claimed. Remaining client and in-game verification items are listed in the project's verification report and fidelity ledger.

**2.0.0 marks the completion of the host-agnostic architecture refactor within the documented scope; it is not a claim of multi-host support or complete content parity.**
