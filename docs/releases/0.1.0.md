Unofficial port of Forbidden Magic 0.574 (Minecraft 1.7.10) for Thaumcraft 4: Reforged 1.1.2 on Minecraft 26.3 / NeoForge 26.3. Requires Java 25 and Thaumcraft 4: Reforged 1.1.2 or newer; the add-on aspect API is part of the stock host since that version. Install on both client and server.

## What is included

Seven sin aspects with their own textures, eight enchantments, the deadly and gluttony shards, chameleon tools, taint materials and the taint tree, Mob Crystal, the Wrath Cage with its spawner and renderer, Heretic trades, functional wand rods and the core caps, the Blink focus with Hellfire and Pandemonium upgrades, the Ring of Nutrition, the Collar of Pain and the Riding Crop. Recipes, research pages and aspect assignments follow `ForbiddenMagic` 0.574; verified differences are listed in `docs/fidelity.md`.

## Host notes

- A stock Thaumcraft 4: Reforged 1.1.2 host is enough to run the port. The aspect registration API this port needs is upstream since that release.
- Scanning the Nether Portal keeps the original NETHER 4 assignment only on a host built with `patches/0001-block-aspect-targets.patch`, which is not upstream yet. Without that patch the portal block has no direct aspect and the mod logs that block aspect targets are unavailable.

## Not included

Content that depends on Blood Magic, Botania, Ars Magica 2 or CoFH is not ported, because those mods have no matching NeoForge 26.3 builds. That covers their items, potions, subtiles, wand rods, caps and cross-mod recipes.

## Known limits

Client-side visuals for the morph tool phase tint, the neutronium wand family and the per-face tainted log textures are implemented and covered by data tests, but have not been confirmed in a running client yet. Report anything that renders or behaves differently from the 1.7.10 original.
