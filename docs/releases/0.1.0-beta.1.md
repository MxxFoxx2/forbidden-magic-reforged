Unofficial port of Forbidden Magic 0.574 for Thaumcraft 4: Reforged on Minecraft 26.3 / NeoForge 26.3. Requires Java 25 and a compatible locally patched Thaumcraft 4: Reforged 1.2 host; the stock published host JAR is not supported yet. Install on both client and server. This is an experimental beta; full parity and all client-side behavior have not yet been confirmed.
