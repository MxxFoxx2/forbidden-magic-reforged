# Верность оригиналу

Порт Forbidden Magic 0.574 (MC 1.7.10). Всё, чего нет в этом файле, перенесено 1:1: те же числа, рецепты,
тексты и поведение, что в `../ForbiddenMagic`. Здесь только отличия, сгруппированные по причине.

Этот файл заменил `docs/deviations.md` и `docs/deviations-closed.md` (удалены 2026-10-22): старые имена
в спеке и планах относятся к нему.

## Форма изменена, возможности те же

Современные идиомы вместо того, что было в 1.7.10; игровых изменений нет.

- Кристалл моба — data-компонент `mob_id` вместо мет 0/1 (с валидацией и синхронизацией).
- Скверный камень — два блока вместо мет; тот же выбор 0/1.
- `enchanting = false` — гасится датапаком и реестром; остаточная запись в реестре игрового эффекта не даёт.
- Скверный rod-update — предикат `TaintBiomes.isTainted` вместо числового biomeID.
- Tainted Wand — `LivingDamageEvent.Pre` проверяет отдельный тип урона `thaumcraft:taint` и восстанавливает по 1 vis для трёх случайных примальных аспектов; это не Taint Poison. Выбрана стадия после проверки неуязвимости и редукции урона, до изменения здоровья.
- Infernal Wand — отмена урона с тегом огня и типа `minecraft:wither` работает только при удержании жезла; очистка огня и Wither остаётся в rod-update владельца.
- Hellfire — `WandTriggers.register` срабатывает по верхней стороне обсидиана/незерака, только при завершённом исследовании `HELLFIRE` и без набалдашника; размещение огня над блоком расходует 2 vis Fire.
- Нечестивый rod-update — компонент `PROFANE_CONTRACT` вместо NBT.
- Стоимость зачарований — min/max в JSON зачарования вместо enchantability.
- Семь осколков грехов — семь отдельных id вместо одного предмета с метами.
- `no_lust` — аспект `luxuria` не регистрируется вовсе (как `DarkAspects.java:28`); осколок остаётся
  в реестре, но называется `despair`, получает текстуру `despair_shard` и VOID 1 вместо
  NETHER/LUST/CRYSTAL (как `ItemDeadlyShard.vices[4]` и `DarkAspects`), остаётся в креативной вкладке;
  текст исследования `NETHERSHARDS` переключается (`FmResearch.java:23`).
- Метки сущностей — `entityCopy` из патча 0002 к хосту.
- Боссы для осколков гордости — явные типы вместо `IBossDisplayData`.
- Картинки исследований — namespace `forbiddenmagic:`.
- Стержни жезлов — `WandRegistry.registerRod`; интеграция с TT — reflection по публичному
  `EnchantmentManager.data()` (TT под ARR, в classpath не входит).
- Ремонт инструментов — компонент `REPAIRABLE`; рецепты — по хост-предметам вместо мет.
- Гейт переключения фаз морф-инструмента — по наличию компонента/зачарования/имени вместо
  `hasTagCompound()`; на практике эквивалентно (свежий инструмент не переключается, зачарованный — да).
- Ore dictionary — теги: `blockNetherStar` → `c:nether_stars`, `resourceTaint` →
  `forbiddenmagic:taint_shards` (в центре арканного рецепта скверного камня).

## Принятые замены

Осознанный выбор, а не ограничение платформы; при желании заменяется.

- Портал — обсидиан вместо отдельного блока портала.
- Банки Клетки Гнева — обычный `warded_jar` вместо своего `empty_jar`.
- Бонус `wrath` — `ATTACK_DAMAGE` плюс зачарования вместо ровного «+1».
- `profaned` стержень — bedrock с программной конверсией (как в оригинале) вместо отдельного предмета.
- Последний кусок Арканного торта — бокс 14/16 (оригинальный 12/12 вырождается).
- Импринт кристалла — карта современных id мобов вместо имён 1.7.10.
- Арканный рецепт скверного камня — в центре FM-осколок скверны; второго варианта из ore dictionary
  (`itemResource` meta 11 у хоста) нет, такого предмета в хосте не зарегистрировано.

## Реализовано, но ещё не закрыто визуальной проверкой

- **Цвет фазы морф-инструмента** — добавлен динамический tint-source для верхнего слоя с исходными
  цветами `0x980000`, `0x0010CC`, `0xE5DA00`. GameTest проверяет таблицу цветов и JSON-модели; перед
  закрытием нужен визуальный `runClient`-гейт.
- **Креативные жезлы** — зарегистрированы neutronium rod (capacity 9001) и staff (9002), update
  восполняет все прималы каждый тик; в creative tab добавлены жезлы tainted/infernal, neutronium,
  neutronium staff и заполненный profane wand (5000 vis на каждый примал). GameTest проверяет данные
  регистрации и содержимое наборов; перед закрытием нужен визуальный `runClient`-гейт.
- **Текстуры скверного бревна** — каждая боковая грань выбирает стандартную, gross или gross2-текстуру
  отдельно по исходному сиду `side + y + x*z`; торцы сохраняют end-текстуру, распределение сторон
  совпадает с оригинальными 75% / 12.5% / 12.5%. GameTest фиксирует исходную формулу и оси; перед
  закрытием нужен визуальный `runClient`-гейт.

## Остаточные отличия

- Чешуйницы — повышенный шанс изумрудного самородка в оригинале привязан к `BiomeGenBase.extremeHills`; в порте использован современный `minecraft:windswept_hills`. Это явное приближение: современная линейка горных биомов не полностью совпадает со старым биомом. Оба шанса и множители Looting перенесены без расширения на прочие горные биомы.

## Не перенесено: внешние моды

Причина одна — портов этих модов под NeoForge 26.3 нет. Код и ассеты не копировались.

- Blood Magic: `ItemBloodRapier`, `DarkPotions` и оба эффекта, `ItemBloodwell`, `ItemBoundwell`,
  `ItemDivineOrb`, алхимический набалдашник (его рецепт и исследование живут в `compat/BloodMagic.java`),
  rod-обновления blood.
- Botania: четыре `SubTile`, `ItemSubCollar`, rod-обновления mana, dreamwood-стержень.
- Ars Magica 2: vinteum-набалдашник, witchwood-рецепты, rod-обновление AM2.
- CoFH: `compat/` целиком.
- Внутренние meta-варианты `ItemResource`, `ItemWandCaps`, `ItemWandCores`, привязанные к материалам этих модов.

## Блокировано хостом

- Распространение скверны — хост держит список заражающих блоков жёстко; нужен патч или апстрим.

## Добавлено нами

Пока ничего. Контракт: добавки не меняют силу, идут за флагом, по умолчанию выключены, и каждая
попадает сюда с указанием флага и значения по умолчанию. Формат — «что, зачем, флаг».
